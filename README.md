# 🎮 Simon Game
 
A browser-based recreation of the classic **Simon** memory game — built from scratch using **HTML, CSS, and JavaScript** (no frameworks, no libraries). Test your memory by repeating an ever-growing sequence of colors and sounds.
 
**[🔗 Live Demo](http://127.0.0.1:5500/index.html)** &nbsp;|&nbsp; **[📂 Source Code](https://github.com/AayushRaj7160/Simon-Game)**
 

 
---
 
## 📖 About the Project
 
Simon is a classic electronic memory game originally released in 1978. This project reimagines it for the web: the game plays a randomly generated, increasingly long sequence of colored button flashes and matching sounds, and the player must repeat the sequence correctly to advance. One wrong move, and it's game over.
 
This project was built to strengthen core front-end fundamentals — DOM manipulation, event handling, and game-state logic — without relying on any external libraries or frameworks.
 
---
 
## ✨ Features
 
- 🎨 Clean, responsive 4-button game board (green, red, yellow, blue)
- 🔊 Authentic sound effects for each button press
- 🧠 Progressively increasing sequence length for growing difficulty
- 💡 Visual and audio feedback on every move
- ❌ Game-over animation/indicator on incorrect input
- 🔁 Instant restart — press any key to start a new game
- 📱 Fully responsive layout for desktop and mobile
---
 
## 🛠️ Built With
 
- **HTML5** — semantic page structure
- **CSS3** — layout, styling, and animations
- **JavaScript (Vanilla, ES6)** — game logic, state management, and DOM manipulation
No external frameworks, libraries, or build tools are used — just the core web stack.

## 🚀 Getting Started
 
### Prerequisites
 
All you need is a modern web browser. No installations, dependencies, or build steps required.
 
### Installation
 
1. Clone the repository
```bash
   git clone https://github.com/AayushRaj7160/Simon-Game.git
```
2. Navigate into the project directory
```bash
   cd Simon-Game
```
3. Open `index.html` in your browser
```bash
   start index.html   # Windows
   open index.html    # macOS
```
 
That's it — no `npm install`, no server required.
 
---
 
## 🎯 How to Play
 
1. Press any key (or click the screen) to start the game.
2. Watch and listen closely as Simon flashes a sequence of colors.
3. Repeat the sequence by clicking the buttons in the same order.
4. Each round adds one more step to the sequence.
5. Make a mistake, and the game resets — see how far you can get!
